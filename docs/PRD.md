# 방명록 시스템 PRD

작성일: 2026-10-22

## 1. 개요

로그인 없이 누구나 이름과 한 줄 메시지를 남길 수 있는 가벼운 웹 방명록이다. 방문자는 다른 사람들이 남긴 글을 읽고, 이름으로 검색할 수 있다.

**이번 범위**: 방명록 화면(글 작성, 목록 조회, 이름 검색)만 설계·구현한다.

## 2. 목표 / 비목표

### 목표
- 누구나 진입 장벽 없이 한마디를 남길 수 있다.
- 욕설이 담긴 글은 금칙어로 등록 단계에서 차단한다.
- 쌓인 글을 최신순으로 편하게 읽고, 이름으로 찾을 수 있다.

### 비목표 (이번 범위 제외)
- 로그인 / 회원 기능
- 관리자 기능 (글 삭제 화면, 금칙어 관리 화면): 추후 별도로 만든다.
- 도배 방지 (등록 간격 제한, IP 제한 등)
- 글 수정 / 방문자에 의한 삭제

## 3. 사용자

- **방문자**: 로그인 없이 글을 쓰고 읽는 모든 사람.
- **운영자**: 부적절한 글을 사후에 삭제한다. 관리자 기능이 생기기 전까지는 DB에서 직접 삭제한다.

## 4. 기능 요구사항

### 4.1 글 작성
- 입력 항목은 **이름**과 **메시지** 두 개다.
- 이름: 필수, 최대 20자. (제안값, 확정 아님)
- 메시지: 필수, 한 줄, 최대 **300자**(한글 기준).
- 등록 시 이름 또는 메시지에 금칙어가 포함되어 있으면 등록을 거부하고 사용자에게 안내 문구를 보여 준다.
- 등록에 성공하면 목록에 즉시 반영된다.

### 4.2 글 목록
- 최신 글이 위에 오는 순서(작성 시각 내림차순)로 보여 준다.
- 한 화면에 **20개**씩 페이지로 나누어 보여 주고, 페이지 이동 UI를 제공한다.
- 각 글에는 이름, 메시지, 작성 시각을 표시한다.

### 4.3 이름 검색
- 이름의 일부만 입력해도 찾아지는 부분 일치 검색이다. (제안값, 확정 아님)
- 검색 결과도 최신순, 20개씩 페이지로 보여 준다.
- 결과가 없으면 빈 상태 문구를 보여 준다.

### 4.4 금칙어
- 금칙어 목록은 서버에서 보관하고, 서버가 등록 요청을 검증할 때 적용한다.
- 이번 범위에서는 금칙어를 관리하는 화면이 없다. 초기 목록은 설정 파일이나 DB 초기 데이터로 넣는다. (제안값)

## 5. 디자인 방향

- 분위기: shadcn/ui 사이트처럼 깔끔하고 미니멀한 느낌.
- 테마 컬러: **연한 파랑**과 **그레이**.
- 스타일링은 shadcn/ui 컴포넌트와 Tailwind CSS를 사용한다. (제안값)
- 목업은 아직 없다. 화면 구성의 세부 사항은 구현 단계에서 정한다.

## 6. 기술 스택

| 영역 | 선택 | 비고 |
|------|------|------|
| 백엔드 | Spring Boot | 사용자 지정 |
| 프론트엔드 | Next.js | 사용자 지정 |
| DB | SQLite | 사용자 지정 |
| UI | shadcn/ui + Tailwind CSS | 제안값 |

## 7. 데이터

글(Entry) 한 건이 가지는 값:
- id
- 이름 (최대 20자)
- 메시지 (최대 300자)
- 작성 시각

## 8. 성공 기준

- 로그인 없이 글을 쓰고, 등록 직후 목록 맨 위에서 확인할 수 있다.
- 금칙어가 포함된 글은 저장되지 않는다.
- 글이 20개를 넘으면 페이지로 나뉘어 보인다.
- 이름 일부로 검색하면 해당 이름의 글만 보인다.

## 9. 사용자가 정한 것과 제안값

**사용자가 정한 것**
- 로그인 없음, 한 줄 방명록, 이름으로 검색
- 부적절한 글은 사후 삭제, 욕설은 금칙어로 제어
- 관리자 기능은 나중에, 이번에는 방명록 화면만
- shadcn 사이트 분위기, 연한 파랑 + 그레이
- Spring Boot + Next.js + SQLite
- 페이지당 20개, 메시지 300자, 도배 방지 없음

**제안값 (확정 필요)**
- 이름 최대 20자
- 최신순 정렬
- 부분 일치 검색
- 금칙어는 등록 단계에서 차단, 초기 목록은 설정 파일 또는 초기 데이터
- shadcn/ui + Tailwind CSS
- 관리자 기능 전까지 삭제는 DB 직접 처리

## 10. 열린 질문

- 금칙어에 걸렸을 때 안내 문구를 어떻게 쓸지 (구체적 문구는 구현 시 정함)
- 이름 중복을 허용할지 (기본값: 허용)
